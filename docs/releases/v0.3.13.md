## Changes

- **Favourites are kept for good.** Every Sonix on the MPC now shares one favourites list. A star stays in every
  project and every new instance until you take it off, and a star set or removed in one open Sonix shows in the
  others right away.
- **Favourites survive upgrades.** The list is saved in the plugin folder's `user/` folder, which installing a new
  version keeps.
- Projects saved with favourites from 0.3.12 or earlier add them to the shared list when they open.

## Fixes

- A new Sonix (or a new project) no longer starts with an empty ★ FAVORITES list.

Includes everything in 0.3.12: the build for second-generation MPCs (`-mpc-aarch64.zip`), the MPC OS 2 faceplate,
and theme and arrow taps that no longer get lost while the transport is stopped.
