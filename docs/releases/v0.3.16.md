# Sonix v0.3.16

## What's new
- **Instruments browser card:** Sonix now shows as its own card in Sounds > INSTRUMENTS. Tapping it opens the plugin's preset list (after the restart the installer does).
- **Presets on the Instruments card:** tapping the Sonix card in Sounds > INSTRUMENTS now lists all 128 factory presets; pick one to load Sonix with that sound.
