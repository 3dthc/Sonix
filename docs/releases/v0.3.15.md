# Sonix v0.3.15

## What's new
- **Desktop VST3 for MPC Desktop and DAWs:** `Sonix-0.3.15-macos-vst3.zip` (one file for Apple Silicon and Intel Macs, with the same touchscreen skin in the plugin window) and `Sonix-0.3.15-windows-vst3.zip` (64-bit; the host shows the parameters, no skin window yet).
- **Device projects open on the computer:** the VST3 has the VST2's official replacement ID, so a project saved on the MPC with this plugin loads it in MPC Desktop (controller mode) instead of showing a missing plugin, with the same sound and settings. A project saved on the desktop opens on the MPC the same way.

## Fixed
- The engine builds for Windows and macOS (Linux-only thread-priority calls are now used only on the MPC).
