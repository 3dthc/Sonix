# Sonix 0.3.13

**Favourites stay.** A star used to live only in the project it was set in, so a new Sonix (or a new project) started
with an empty favourites list. Now every Sonix on the MPC shares one list, kept in `engine/favorites.txt` next to the
instruments:
- a star stays until you take it off, in every project and every new instance;
- two Sonix open at once stay in step (a star set in one shows in the other);
- a project saved with stars of its own (0.3.12 and earlier) adds them to the list when it opens;
- upgrading Sonix keeps the file.

Check on the device: star a preset, add Sonix to another track (or start a new project): ★ FAVORITES lists it. Restart
the MPC: still there. Take the star off: gone everywhere.
